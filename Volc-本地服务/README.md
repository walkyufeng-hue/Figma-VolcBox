# 🌋 Volc-本地服务 (本地增强自用版)

本文件夹为 **本地个人日常使用完整增强版（保留本地服务与剪贴板助手）**。

---

### 🔥 增强特性
1. **本地剪贴板直拷服务 (3055 端口)**：
   - 支持在插件界面直接下载并一键启动本地助手；
   - 拼图大图直拷到系统剪贴板（微信/飞书按 `⌘+V` 直接发送）；
   - 多画板一键直拷多张图片到 macOS Finder 剪贴板。
2. **全套完整功能**：
   - 包含多语言翻译、图片压缩、全局调色、PNG 透明留白裁切等全部能力。

---

### 🚀 如何在 Figma 中使用本版本
1. 打开 Figma 桌面端；
2. 在插件面板中选择 **`Import plugin from manifest...`（从清单导入插件）**；
3. 选中本文件夹中的 **`manifest.json`**；
4. 即可在本地享受完整无删减的极速设计体验！
